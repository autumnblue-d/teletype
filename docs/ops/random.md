## Randomness

These operators generate randomness in several flavours: uniform draws (`RAND`, `RRAND`, `TOSS`, `R`), the random walk (`DRUNK`), chaotic maps (`CHAOS`), beta-shaped distributions (`BETA`, `BETA.K`), and the Marbles-style déjà-vu random-loop engine (`DV` and friends). Dedicated `*.SEED` ops make each generator's output reproducible.
